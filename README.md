# FNR Engine
**FNR Engine**, or **Fall and Rise Engine**, is a generic engine that started as a *Framework* for my *RP Forum* [Fall and Rise](https://fallandrise-rpg.foroactivo.com/) back in 2018 which evolved in an opinionated way for building *skins* on the [Forumotion](https://www.forumotion.com/) platform. In my opinion a far better way than vanilla, and better than other alternatives. But I made it, makes sense that I say that.

The publication of it on [Github](https://github.com/) is because I plan to publish it under the [MIT License](https://mit-license.org/), and make it an *Open Source Project*. I might even document it.

It has to be taken into account that this is useless without it's implementation on the **Forumotion** Templates, as well as a sister repo for the *skin*.
